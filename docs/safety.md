# ميثاق السلامة

1. كل اختبار يتطلب ملكية أو تفويضاً مكتوباً.
2. لا تُدرج أهدافاً عامة أو بيانات اعتماد حقيقية في التحديات.
3. الوضع الافتراضي `dry-run` ولا يرسل طلبات مؤثرة.
4. تُحظر سرقة بيانات الاعتماد، تجاوز المصادقة، البرمجيات الخبيثة، الاستمرارية، التخفي، التصيد، وتخريب الخدمة.
5. يجب أن تكون المختبرات محلية أو خاصة ومعزولة، مع بيانات وهمية.
6. كل عملية تسجل المنفذ والهدف والوقت والنتيجة.
7. أي إضافة يومية تمر عبر الاختبارات وتوثق نطاقها قبل الدمج.
8. عند اكتشاف ثغرة حقيقية، أوقف الاختبار واتبع إفصاحاً منسقاً مع مالك النظام.
